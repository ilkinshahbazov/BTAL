# Bakü Türk Ortaokulu İngilizce Zümresi

5, 6, 7 ve 8. sınıf İngilizce ders kitaplarına ulaşmak için hazırlanmış sade,
mobil uyumlu bir web sayfasıdır.

## Yayınlama

`main` dalına gönderilen her değişiklik GitHub Actions ile GitHub Pages'e
otomatik olarak yayınlanır. İlk kullanımda depo ayarlarından **Settings → Pages
→ Source → GitHub Actions** seçilmelidir.

## Kitap bağlantılarını güncelleme

Bağlantılar `site/index.html` dosyasındaki sınıf kartlarında bulunur. İleride
kitapları depoya yüklemek isterseniz PDF dosyalarını `site/kitaplar/` klasörüne
ekleyip kartlardaki `href` adreslerini bu dosyalara çevirebilirsiniz.
